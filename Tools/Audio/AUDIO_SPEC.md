# Rocky Kombat — audio asset specification (for the procedural generator)

Target project: `C:\RockyKombat` (UE 5.8, Paper2D fighting game).
Deliver into `C:\RockyKombat\ArtSource\Audio\`, generated by `C:\RockyKombat\Tools\Audio\rkc_generate_audio.py`.

## Hard rules

- Pure synthesis only, from math: oscillators, noise, envelopes, filters. NO downloads, NO network, NO
  sample libraries, NO copying recognizable sounds or music from any commercial fighting game.
- Only already-installed packages: numpy 2.4.6 and the stdlib `wave` module. Do not install anything
  (no scipy). Verify with `python --version` and `python -c "import numpy"` first.
- Deterministic: fixed seed, so re-running reproduces the same files.
- Format: 44100 Hz, 16-bit PCM WAV. Mono for effects and voices, stereo for music and ambience.
- Loudness: normalise each file to a sensible target, and keep peaks <= -1.0 dBFS. No clipping.
- No file larger than 10 MB.

## Voice synthesis method

Do not attempt intelligible speech. Synthesize stylized animal-like non-verbal vocalisations: a pitched
glottal pulse train or filtered noise shaped by 2-3 resonant bandpass formants, with pitch and formant
envelopes over time. Each numbered variant in a set must differ audibly — vary pitch, formant centres,
duration and jitter so that a repeated action does not play an identical sound every time.
